Backend dùng TypeScript, Express, Prisma và PostgreSQL 18. Xem hướng dẫn P3 trước khi migrate database đã có dữ liệu.

Admin web (`apps/admin-web`) dùng React 18, TypeScript và Tailwind CSS v4. Chạy `npm run dev` trong thư mục đó để bật chế độ mock — không cần backend.
